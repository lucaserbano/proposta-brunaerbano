# proposta-brunaerbano

Proposta comercial da Ars · Branding na Saúde em formato de site (não indexado).
Branding e identidade visual para médica cardiologista e ecocardiografista, especializada em doenças valvares cardíacas.

## Publicar
1. GitHub → Settings → Pages → Deploy from a branch → `main` / `(root)`.
2. Endereço: https://lucaserbano.github.io/proposta-brunaerbano/ (CSS/JS versionados com `?v=N`; aumente o N a cada mudança para evitar cache).
3. Adobe Fonts: adicionar o domínio publicado ao projeto web `fzu1yoy` para a Canto carregar.

## Identidade
- Canto Bold (Adobe Fonts, tracking -25) + Open Sans Light (tracking 0).
- Paleta: Pine Teal `#134047`, Powder Petal `#F1DECF`, Verdigris `#15998C`, Black `#000000`.
- Pattern 2 sempre sobre fundo verde (`.tema-escuro.com-pattern-2`).
- Zona de segurança da logo: 40% da altura da logo (`.logo-zona`).

## Valores
Os valores ficam em `assets/js/pacote.js` (cheio R$ 3.660, cupom SISTER → R$ 1.220; opcional R$ 900). Testes: `node --test`.
